# Training Plan

Personal offline web app for a 25-week 5K and cricket pre-season plan. Static files only: no accounts, server or tracking. Logs stay in the browser storage of the device.

## Deploy to GitHub Pages

1. Create a repository called `training-plan` on GitHub.
2. Upload the contents of this folder to the root of the repository.
3. In **Settings → Pages**, deploy from branch `main`, folder `/ (root)`.
4. Open `https://USERNAME.github.io/training-plan/` in Safari on iPhone, then **Share → Add to Home Screen**.

To update, upload the changed files again. The app picks up changes the second time it is opened online.
